SchemaZone how-to

How to upload your .sql file to your Zone

Four steps from your database to a diagram. “Upload” here means opening the file in SchemaZone: it is read on your own computer and never sent anywhere.

  1. 1

    Export your schema as a .sql file

    Pick your database and run the command. Replace USER and DATABASE with your own values.

    MySQL / MariaDB

    mysqldump --no-data -u USER -p DATABASE > schema.sql

    PostgreSQL

    pg_dump --schema-only -U USER DATABASE > schema.sql

    SQL Server

    1. In SSMS, right-click the database.
    2. Choose Tasks → Generate Scripts.
    3. Choose the tables.
    4. Open Advanced and set “Types of data to script” to Schema only.
    5. Save as schema.sql.

    SQLite

    sqlite3 my.db .schema > schema.sql

    A full dump with data also works. SchemaZone reads only the table definitions and skips the rows.

  2. 2

    Open your Zone

    Go to hasanradi93.github.io/razov-db/schemazone/ and choose “New Zone”.

    hasanradi93.github.io/razov-db/schemazone/ New Zone
  3. 3

    Drop your .sql file

    Drop it onto the drop area, or click to choose it. It's read on your own computer and nothing is uploaded.

    schema.sql Drop your .sql file here, or click to choose
  4. 4

    Explore, edit and export

    Your tables and relationships appear as a diagram. Drag, focus, edit, then export as .sql or .json. The Zone is saved in this browser, so you can come back to it.

Questions about your .sql file

Is my file uploaded?

No. SchemaZone reads the file inside your browser. It never leaves your computer.

What size of file works?

SchemaZone has been tested with large schemas. Files under 20 MB work best.

What if some statements are skipped?

SchemaZone shows a report of anything it skipped.

Can I move my Zone to another computer?

Yes. Export it as a .json Zone file and open it there.

Does it need the rows in my tables?

No. A schema-only export is enough. A full dump with data also works; SchemaZone reads only the table definitions and skips the rows.
